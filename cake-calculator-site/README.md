# Калькулятор торта: автообновление цен

Раз в сутки (07:00 МСК) GitHub сам запускает `scripts/update-prices.mjs`: скрипт ищет цены через TinyFish Search, обновляет `prices.json` и коммитит его. Netlify видит коммит, пересобирает сайт, и калькулятор показывает свежие цены и дату обновления.
Если обновление не удалось (мало найденных цен, ключ не принят), старый `prices.json` остаётся, а GitHub пришлёт письмо о сбое.

## Настройка (один раз, ~15 минут)

1. **GitHub.** Создайте новый репозиторий (например, `cake-calculator`) и загрузите в него всё содержимое этой папки, включая скрытую папку `.github` (на Mac: Cmd+Shift+. в окне выбора файлов).
2. **Ключ TinyFish.** Откройте https://agent.tinyfish.ai/api-keys и создайте ключ. Поиск бесплатный.
3. **Секрет в GitHub.** Репозиторий → Settings → Secrets and variables → Actions → New repository secret. Имя: `TINYFISH_API_KEY`, значение: ваш ключ. Никому не отправляйте ключ, в том числе в чат.
4. **Netlify.** Add new site → Import an existing project → выберите репозиторий. Настройки сборки менять не нужно: `netlify.toml` уже всё содержит (publish directory = `.`, команда сборки пустая).
5. **Первый запуск.** Репозиторий → Actions → «Update prices» → Run workflow. Через несколько минут в репозитории появится коммит от `price-bot`, а сайт обновится.

## Проверка локально

```
node --test test/parse.test.mjs
TINYFISH_API_KEY=... node scripts/update-prices.mjs
```

## Что важно знать

- Цены берутся из поисковой выдачи и сниппетов страниц магазинов. Это Москва, обычные цены без карт лояльности. Для каждой цены берётся медиана нескольких находок, а выбросы отбрасываются.
- Если для товара ничего подходящего не нашлось, остаётся прошлое значение. Если данным больше 14 дней, калькулятор пишет «данные могли устареть».
- Цены ориентировочные. Для публичного сайта оставьте пометку «цены приблизительные» и учитывайте правила сайтов магазинов.
- Чтобы добавить продукт или сеть, поправьте `INGREDIENTS` или `CHAINS` в `scripts/update-prices.mjs` и список `CHAINS` в `index.html`.
