# Сайт на роутере с OpenWrt — пошагово с iPhone

После настройки сайт открывается по адресам:
- **из интернета:** `http://tettapro.duckdns.org` (имя выбираете сами в шаге 3);
- **дома или в офисе:** `http://192.168.1.1:8088` (адрес вашего роутера и порт 8088).

На iPhone его можно добавить на экран «Домой»: появится иконка θ с подписью «TettaPRO».
Настройка занимает 15–20 минут. Прошивку менять не нужно: используется встроенный веб-сервер OpenWrt.

## 0. Что понадобится

- **На iPhone:** бесплатное приложение **Termius** из App Store. Через него подаются команды роутеру и копируются файлы.
- **Архив сайта** `analogs-tettapro.zip`, сохранённый в приложение «Файлы». Распаковывать его не нужно.
- **Пароль root роутера** — тот же, что для входа в LuCI.
  Если пароля нет, задайте его в LuCI: **Система → Администрирование → Пароль маршрутизатора**.
- **Интернет на роутере:** он скачает пару небольших пакетов.

## 1. Подключиться к роутеру из Termius

1. Termius → **Hosts → «+» → New Host**:
   - Address: `192.168.1.1` (адрес LuCI вашего роутера);
   - Username: `root`;
   - Password: пароль роутера.
2. Нажмите на созданный хост — откроется окно для команд.
3. Скопируйте и выполните команду. Она ставит программы для приёма файлов и распаковки архива:

```
command -v apk >/dev/null && { apk update; apk add openssh-sftp-server unzip; } || { opkg update; opkg install openssh-sftp-server unzip; }
```

## 2. Залить архив сайта на роутер

1. В Termius откройте вкладку **SFTP** и выберите хост роутера.
2. Перейдите в папку `/tmp`.
3. Нажмите **«+» / Upload → Files** и выберите `analogs-tettapro.zip`.

Если в Termius нет SFTP, подойдёт приложение **Secure ShellFish**. Оно добавляет роутер прямо в «Файлы», и архив можно скопировать в `/tmp` обычным перетаскиванием.

## 3. Бесплатное имя сайта (DuckDNS)

1. В Safari откройте **duckdns.org** и войдите через Google, GitHub, Reddit или X.
2. В поле **sub domain** введите имя, например `tettapro`, и нажмите **add domain**.
   Если имя занято, попробуйте `tettapro-podbor`, `tettapro-analogi` и т. п.
3. Вверху страницы будет строка **token** — длинный код вида `a1b2c3d4-…`. Скопируйте его.

## 4. Установить сайт одной командой

В окне команд Termius выполните, подставив своё имя и токен:

```
cd /tmp && rm -rf analogs-tettapro && unzip -q -o analogs-tettapro.zip -d analogs-tettapro && sh analogs-tettapro/router/openwrt-setup.sh tettapro ВАШ-ТОКЕН
```

Скрипт:
- копирует сайт в постоянную память роутера, а если там мало места — на USB-флешку;
- запускает веб-сервер на порту 8088 (LuCI продолжает работать как раньше);
- открывает доступ из интернета;
- настраивает имя `tettapro.duckdns.org`.

Служебные файлы (`admin.html`, Excel-база, скрипты) на роутер не копируются. В конце скрипт напишет адреса сайта.

Без имени (только по IP) команда та же, но без `tettapro ВАШ-ТОКЕН` в конце.

## 5. Проверить

1. **На iPhone по Wi-Fi роутера** откройте `http://192.168.1.1:8088`.
2. **Выключите Wi-Fi** и откройте `http://tettapro.duckdns.org`. В первый раз подождите 5–10 минут, пока имя заработает.
   Если провайдер блокирует порт 80, откройте адрес с портом: `http://tettapro.duckdns.org:8088`.
3. **Иконка на экран «Домой»:** Safari → **Поделиться → На экран «Домой» → Добавить**.

## Если из интернета не открывается

Скрипт в конце предупредит, если внешний адрес роутера «серый». Такое бывает в двух случаях:

- **Роутер с OpenWrt подключён к роутеру провайдера.** В настройках роутера провайдера сделайте проброс
  портов 80 и 8088 на адрес OpenWrt-роутера. Или включите на роутере провайдера режим «мост» (bridge).
- **Провайдер выдаёт «серый» адрес (CGNAT).** Закажите у него услугу «белый (публичный) IP-адрес».
  Обычно это 100–200 ₽ в месяц.

## Обновление сайта

Например, если вышла новая база блоков питания:
1. Залейте новый `analogs-tettapro.zip` в `/tmp` (шаг 2).
2. Выполните ту же команду из шага 4.

Настройки сохранятся. Повторный запуск ничего не дублирует.

## Полезные команды

| Что нужно | Команда |
|---|---|
| Перезапустить веб-сервер | `/etc/init.d/uhttpd restart` |
| Посмотреть ошибки | `logread \| grep -E "uhttpd\|ddns"` |
| Убрать сайт с роутера | `sh /tmp/analogs-tettapro/router/openwrt-setup.sh uninstall` (архив должен быть распакован в `/tmp`) |
| Сменить порт или отключить доступ без порта | переменные `PORT` и `OPEN_PORT_80` в начале `router/openwrt-setup.sh` |

**Безопасность.** Сайт статический и только отдаёт файлы. LuCI и SSH из интернета закрыты, как и были:
скрипт открывает только порт сайта.
