# TETTAPRO — подбор аналогов блоков питания

Программа для Windows: вводите артикул блока питания другого бренда (например, Mean Well `MDR-20-24`),
нажимаете «Поиск» — программа показывает аналог TETTAPRO (`MTPR-M02024`).

## Запуск
Скопируйте `TettaPRO-Analogs.exe` в любую папку и запустите. Установка не нужна:
используется .NET Framework 4.8, который уже есть в Windows 10 и 11.

## Возможности
- поиск без учёта регистра, пробелов и дефисов (`mdr 20 24` = `MDR-20-24`);
- если аналогов несколько — показываются все (например, `NDR-240-24` → `MTPR-E24024 / MTPR-X24024`);
- обратный поиск: ввод артикула TETTAPRO показывает, какие модели он заменяет;
- частичный поиск: `HDR` покажет все модели серии;
- автодополнение артикулов, копирование результата, двойной клик по строке таблицы копирует аналог.

## Обновление таблицы замены
Таблица встроена в программу. Чтобы заменить её, положите рядом с exe файл `analogs.xlsx`
или нажмите «Загрузить таблицу…» внизу окна. Формат: строка-заголовок с колонкой `TettaPRO`
и колонками брендов (`MeanWell` и любые другие — каждая станет пунктом в списке «Бренд»).

## Логотип
Если рядом с exe лежит `logo.png`, он показывается в шапке вместо фирменной надписи.

## Сборка
```
dotnet build -c Release
```
Результат: `bin/Release/net48/TettaPRO-Analogs.exe`.
