# Сайт на роутере ASUS — настройка с iPhone

В итоге сайт откроется по адресам:
- из интернета: `http://tettapro.asuscomm.com` (имя выбираете сами в шаге 6);
- дома или в офисе: `http://192.168.50.1:8088`.

На iPhone его можно добавить на экран «Домой»: появится красная иконка θ с подписью «TettaPRO».

Всё делается один раз, примерно за 30–40 минут.

## Что понадобится

- **Роутер ASUS, который поддерживает прошивку Asuswrt-Merlin.** Список моделей есть на сайте
  asuswrt-merlin.net (раздел Download). Подходят почти все RT-AX…, RT-AC…, GT-… и ZenWiFi XT8/XD4.
  Если вашей модели нет в списке, напишите её название: подскажем другой вариант.
- **USB-флешка на 4 ГБ или больше.** Её отформатируют, все данные на ней удалятся.
- **На iPhone:** Safari, приложение «Файлы» и бесплатное приложение **Termius** (App Store) для команд роутеру.
- **«Белый» IP-адрес у провайдера,** иначе сайт будет доступен только внутри сети. Как это проверить, описано в шаге 6.

## 1. Прошивка Asuswrt-Merlin

1. В Safari откройте asuswrt-merlin.net → **Download** и скачайте архив для своей модели.
   В «Файлах» нажмите на архив: он распакуется, внутри будет файл прошивки `.w` или `.pkgtb`.
2. Откройте настройки роутера: `http://router.asus.com`. Если не открывается, попробуйте `http://192.168.50.1`
   или `http://192.168.1.1`.
3. **Администрирование → Обновление микропрограммы → Загрузить** и выберите файл прошивки.
   Дождитесь перезагрузки, это 3–5 минут. Настройки роутера сохранятся.

## 2. Доступ для команд

**Администрирование → Система:**
- **Enable JFFS custom scripts and configs** → **Да**;
- **Включить SSH** → **LAN only** (только из локальной сети), порт 22.

Нажмите **Применить**.

## 3. Флешка и Entware

1. Вставьте флешку в USB-порт роутера.
2. В Termius создайте подключение (New Host):
   - адрес `192.168.50.1` (или адрес из шага 1.2);
   - порт 22;
   - логин и пароль — те же, что для входа в настройки роутера.
3. Введите `amtm` и нажмите Enter. В меню amtm:
   - **fd** — отформатировать флешку (выберите ext4). Если флешка уже в ext4, этот пункт можно пропустить.
   - **ep** — установить Entware (менеджер программ для роутера).

   Названия пунктов в разных версиях amtm могут чуть отличаться. Ищите «Format disk» и «Entware».
4. Выйдите из amtm: **e**.

## 4. Копирование сайта на флешку

1. В настройках роутера включите общий доступ к флешке:
   **USB-приложение → Сетевой ресурс (Samba)** → **Включить общий доступ**.
2. Скачайте на iPhone архив `analogs-tettapro.zip` и распакуйте его в «Файлах» нажатием.
   Появится папка `analogs-tettapro`.
3. В «Файлах»: **Обзор → «…» (справа вверху) → Подключиться к серверу** → `smb://192.168.50.1` →
   введите логин и пароль роутера.
4. Скопируйте папку `analogs-tettapro` в корень флешки.

## 5. Запуск сайта

В Termius выполните одну команду:

```
sh /tmp/mnt/*/analogs-tettapro/router/setup.sh
```

Скрипт:
- ставит веб-сервер;
- раздаёт сайт;
- открывает доступ из интернета;
- закрывает служебные файлы (`admin.html`, Excel-базу);
- настраивает автозапуск после перезагрузки.

В конце он напишет адреса сайта. Если внешний адрес роутера окажется «серым», скрипт предупредит.

Проверьте, что дома сайт открывается: `http://192.168.50.1:8088`.

## 6. Название сайта в интернете (DDNS)

1. **Интернет → DDNS:**
   - **Включить DDNS-клиент** → Да;
   - **Сервер** → `WWW.ASUS.COM`;
   - **Имя хоста** → например `tettapro`.

   Если имя занято, попробуйте `tettapro-analogi`, `tettapro-podbor` и т. п.
2. Нажмите **Применить**. Адрес сайта будет `http://tettapro.asuscomm.com`.
3. **Проверка «белого» IP:** на главной странице настроек роутера посмотрите «WAN IP». Затем на iPhone
   с выключенным Wi-Fi откройте 2ip.ru и сравните адреса.
   - Совпадают — всё в порядке.
   - Не совпадают, или WAN IP начинается на `10.`, `100.64–100.127`, `172.16–31.` или `192.168.` — адрес «серый».
     Закажите у провайдера услугу «белый (публичный) IP-адрес». Обычно это 100–200 ₽ в месяц.
4. **Проверка снаружи:** выключите Wi-Fi на iPhone и откройте `http://tettapro.asuscomm.com`.
   Если провайдер блокирует порт 80, сайт откроется по адресу с портом: `http://tettapro.asuscomm.com:8088`.

## 7. Иконка на iPhone

Откройте сайт в Safari → **Поделиться → На экран «Домой»** → **Добавить**.
Сайт будет открываться как приложение, без адресной строки.

## Как обновить сайт

1. Подключитесь к флешке в «Файлах» (шаг 4.3).
2. Замените файлы в папке `analogs-tettapro`, например новый `data/db.js` после обновления базы.

Ничего перезапускать не нужно.

## Если что-то не работает

- **Сайт не открывается дома.** В Termius выполните `/opt/etc/init.d/S80lighttpd restart`.
  Журнал ошибок: `cat /opt/var/log/lighttpd-error.log`.
- **Нужно убрать сайт с роутера:** `sh /tmp/mnt/*/analogs-tettapro/router/setup.sh uninstall`.
- **Сменить порт** (по умолчанию 8088) или **отключить доступ без порта:** измените переменные `PORT` и `OPEN_PORT_80`
  в начале `router/setup.sh` и запустите его снова.
- **Сертификат Let's Encrypt для DDNS.** Если вы включили его в настройках DDNS, порт 80 нужен роутеру для продления
  сертификата. В этом случае поставьте `OPEN_PORT_80=0` и открывайте сайт с портом `:8088`.
- **Безопасность.** Сайт статический и только отдаёт файлы. Настройки роутера из интернета не открываются.
  SSH доступен только из локальной сети. Не включайте «Доступ к веб-интерфейсу из WAN», если он не нужен.
